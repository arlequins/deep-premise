# Unseen Order 0.10.0

Sixfold is now the default game: a twelve-gate creature-building roguelike with three bosses, fifteen organs, six relics, and late-game enemy traits.

- Organ replacement preserves its level and temporarily accelerates the replacement for one battle.
- The six-slot board shows activation bars, active links, and upgrade previews.
- Added armor piercing, life steal, poison conversion, shield conversion, attack delay, and heavy attacks.
- Fixed a full-board replacement crash caused by an expired draft selection.
- Korean and English are available in the game.
- Existing prototypes and save files are preserved. Type10 remains an archived experiment.

The Windows installer includes the engine and .NET runtime, installs for the current user, and creates Start menu and desktop shortcuts. Saves and detailed game logs are stored under `%APPDATA%/UnseenOrder`; uninstalling the application preserves them.

This is an unsigned prototype release. No Steam integration, paid AI, or BGM is included.
